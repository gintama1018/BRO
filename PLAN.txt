GUIDING PHILOSOPHY & INVARIANTS
---------------------------------------------------------------
1. Core browser stability first (Zero AI dependency).
2. Deterministic security gate second (Zero AI dependency).
3. Ad, tracker, and download shielding third (Zero AI dependency).
4. Spatial multitasking (Nova QuadView) fourth (Zero AI dependency).
5. Local AI added strictly as an additive layer on top of a secure browser.

PHASE 2 — SECURITY, SHIELDS & QUADVIEW WORKSPACE
---------------------------------------------------------------
[x] Deterministic Security Gate:
    - UrlCanonicalizer: Punycode conversion, percent-decoding, port normalization.
    - ThreatFeedManager: Local URLhaus malware dataset fast matching (5,057+ rules).
    - HeuristicsEngine: Levenshtein distance brand typosquatting + Shannon entropy.
    - RedirectTracker: 4-hop limit enforcement + SSL-stripping downgrade detection.
    - "UNKNOWN != SAFE" invariant strictly maintained.
[x] Explainable Security Warning screen (SecurityWarningActivity) with risk factors.
[x] Network Ad & Tracker Blocking (AdBlockEngine):
    - Fast-path subresource filtering in O(labels) lookup time (9,578 domain rules).
[x] Cosmetic DOM Element Hiding (CosmeticEngine):
    - 118 batched CSS hiding rules injected on page finish.
[x] Site Shields Manager (SiteShieldManager):
    - Granular per-domain toggles for shields, adblock, cosmetic, JS, and cookies.
[x] Download Quarantine Sandbox (DownloadHandler):
    - Risky files (.apk, .dex, .sh, .exe, .js) routed to .nova_quarantine/.
    - Running SHA-256 digest calculated; explicit user confirmation required.
[x] Nova QuadView (Spatial Multi-Tab Workspace):
    - Up to four live tabs displayed simultaneously in a responsive 2x2 grid.
    - Preserves live WebViews via view reparenting ("Layout change != session recreation").
    - Focus Mode expansion, slot-to-slot swapping, and contextual pane controls.
    - Strict privacy boundary: standard and private tabs cannot mix in QuadView.
[x] In-App Security Diagnostics Self-Check Runner (NovaDiagnostics).
